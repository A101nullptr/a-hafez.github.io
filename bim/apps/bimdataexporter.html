BimDataExporter

A folder of Revit models, turned into structured data

Platform | Revit · GIS and database use
Stack | C# / .NET · Revit API · JSON · GeoJSON · WKT · coordinate transformation

Models hold data that GIS tools, databases and web maps need, but it stays locked inside Revit files. From the active model's folder, this add-in batch-processes every .rvt into structured files, with three separate exports for different consumers. Rooms come out georeferenced: boundaries are converted from Gauss-Krüger to WGS84, so they land in the right place on a map.

Three exports

Design decisions

Georeferenced roomsStandard GeoJSON means rooms open directly in web maps and GIS tools.
Batch by designIt reads sibling .rvt files, so one click covers a whole project folder.
Separate exportsEach consumer gets only what it needs, in its own folder.
