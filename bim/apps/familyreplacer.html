FamilyReplacer

Swap family types across open documents, safely

Platform | Revit
Stack | C# / .NET · WPF · Revit API · JSON configuration

Replacing a family type in several open projects means repeating the same steps in each, and groups often get in the way. FamilyReplacer lets you pick a source type in the active document and a target type in another open document, queue as many pairs as you need, and swap every matching instance. Conflicts with groups are handled, a failed document rolls back on its own, and each document gets its own log.

How it works

Design decisions

Failure stays containedPer-document rollback means one problem model doesn't undo the others.
You stay in controlOld families are only deleted after you confirm.
A record of every runLogs are kept and linked from the summary, while temporary files are removed.
