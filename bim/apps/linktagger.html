LinkTagger

Tags for elements inside linked models

Platform | Revit · linked models
Stack | C# / .NET · WPF · Revit API

Tagging elements that live in linked models is slow in Revit, one at a time. LinkTagger searches every linked model for walls, generic models and structural framing, filters by the ElementTyp parameter, and tags every match in the active plan view with the family and type you choose. An optional grid layout then tidies the result, and tags whose leader no longer reaches its host are highlighted.

How it works

Design decisions

Reaches into linksIt tags through to elements in other models, in floor and ceiling plans.
Readable outputA temporary grid sorts tags by position, moves each to a free cell and straightens leaders.
Clean afterwardsGrid and detail lines are removed at the end, unless you choose to keep the grid.
