FamilyUpdater

Changed families, found and loaded without hunting for them

Platform | Revit · shared family library
Stack | C# / .NET · WPF · Revit API · FileSystemWatcher · system-tray app

When families change in a shared library, somebody has to know which ones and load them into every project. This tool has two cooperating parts: a tray app that watches the family folder and records every change, and a Revit add-in that shows which families changed and haven't yet been applied. Select them and press Update: they are loaded with overwrite, and recorded so they don't appear again. The video also shows the rollout workflow across cloud models: tick families on the left and target models on the right, and each model is opened, updated, synchronised and reported by email.

How it works

Design decisions

Decoupled watcherThe watcher runs alone in the tray, so changes are captured even when Revit is closed.
Plain log filesA readable shared log connects the two programs, also across machines.
IdempotentApplied families are recorded, so a family is never offered twice.
