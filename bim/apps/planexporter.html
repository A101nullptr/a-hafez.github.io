PlanExporter

Sheets out to PDF and DWG, already correctly named

Platform | Revit
Stack | C# / .NET · WinForms · Revit API · QR code generation

Handing out plans means exporting sheets and then renaming every file. PlanExporter replaces that with a tree of sheets, a choice of single files or one combined document, optional DWGs and QR codes, and naming rules that build each file name from project, sheet or view parameters. The output folder is ready to hand out as soon as it finishes.
