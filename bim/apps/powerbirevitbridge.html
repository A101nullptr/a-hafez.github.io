PowerBiRevitBridge

From a report row to the element in the model

Platform | Power BI · Revit
Stack | C# / .NET · Revit API · Win32 clipboard listener · system-tray app · JSON

A Power BI report can tell you which elements have a problem, but finding them in Revit means looking up IDs by hand. With this bridge, copying the cells in the report is enough: Revit selects and isolates those elements straight away. The clipboard is the channel between the report and the model. Two small programs cooperate: a tray agent that recognises what was copied, and a Revit add-in that reacts to clipboard changes and checks the data before acting on it.

How it works

The clipboard payload

{
  "revit-file-identifier": {
    "ProjektID": "…", "GebaeudeHaus": "…",
    "GebaeudeCode": "…", "HausCode": "…"
  },
  "tags": ["12345678", "12345679"]
}

Design decisions

Event-drivenThe add-in uses AddClipboardFormatListener, so it reacts to changes and never polls.
Refuses the wrong modelThe project identifiers from the report are compared with the open document's project information before anything is selected.
Reports what's missingIDs that no longer exist in the model are listed in a dialog instead of being silently dropped.
