Schalungskegel

Formwork cones placed by structural rules

Platform | Revit · timber-concrete composite (HBV) ceilings
Stack | C# / .NET · Revit API · solid geometry · JSON configuration

Formwork cones in timber-concrete composite ceilings follow strict spacing rules, which makes placing them by hand slow and easy to get wrong. This add-in reads the geometry of each ceiling element, works out where the cones belong and places the correct family type at every point. A pre-check flags ceiling elements too complex to process, and it can draw the used and leftover paths in the model, so the result can be checked instead of trusted.

The placement rules

From geometry to placed cones

  1. Collision detection: find the bottom face of the ceiling and test which edges actually meet a wall, using a 100 mm vertical drop check.
  2. Special walls: if a ceiling meets certain wall types, ignore its long edges and use only the short ones.
  3. Path offset: move the support edges into the ceiling by 60 mm, or 65 mm for K-DA ceilings.
  4. Start offset: push the start of the path in by 250 mm so the first cone stays clear of the corner.
  5. Segmentation: middle segments must be 300–600 mm and the last 140–500 mm. Long segments are split, and a last segment that is too short is balanced against the one before it.
  6. Placement: map the ceiling type to its family through elementKeys.json and place an instance at every point.
