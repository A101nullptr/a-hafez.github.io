TagPlacer

Tags placed by rules, with a strategy for each element type

Platform | Revit
Stack | C# / .NET · WPF · Revit API

Dense plans need tags that don't collide, and the best position depends on the kind of element. TagPlacer works from a grid of rules, one per row: an element type prefix, a tag family and type, a placement strategy and leader options. Run it, and every matching element in the active view is tagged, in floor, ceiling, engineering and area plans, elevations, sections and details.

Four placement strategies

Design decisions

A rule per rowDifferent element types can use different strategies in a single run.
Finds free spaceNormal searches within 50 mm in 5 mm steps, and falls back to centred if nothing fits.
Geometry-based groupingPairs need a gap of at most 20 mm and 1° of angle, and clusters are centroids within 500 mm.
Leaders that make senseFree-end leaders on walls anchor at least 50 mm from openings.
