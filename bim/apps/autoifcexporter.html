AutoIfcExporter

Unattended IFC export from the cloud

Platform | Revit · Autodesk Construction Cloud · SharePoint
Stack | C# / .NET 4.8 · Revit API · APS Data Management API · Microsoft Graph · SharePoint CSOM · Task Scheduler

A scheduled server-side pipeline. It reads which models are on Autodesk Construction Cloud, decides which ones need exporting, opens them in a real Revit instance, exports IFC, publishes the results to SharePoint and emails a log. Nobody has to be at the machine. Cloud conversion would charge Flex tokens on every scheduled run. Running the conversion in local Revit avoids that and keeps the project's own export setup, while ACC still decides which models are in scope.

How the pipeline runs

Design decisions

Local conversion, not cloudThe IFC conversion runs inside a real Revit instance instead of APS Model Derivative.
No per-conversion costAvoids Flex token charges on every scheduled run.
Exact output preservedThe project's own IFC export configuration and named view selection are used as they are.
Three separate programsSetup, the add-in and Cleanup each do one job, so Cleanup can shut down and remove the add-in that started it.

Pipeline steps

  1. Task Scheduler runs Setup, which reads its configuration.
  2. In FilterMethod mode it filters the ACC models, writes data.json and selection.json, uploads the daily data to SharePoint and exits.
  3. In SelectionMethod mode it authenticates, loads selection.json, downloads files where needed, copies the Revit add-in and boots Revit.
  4. The add-in opens the selected models, exports the IFC views and starts Cleanup.
  5. Cleanup terminates Revit, removes the add-in, uploads the IFC files, emails the log and deletes temporary folders.
