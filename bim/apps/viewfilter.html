ViewFilter

Every view-filter task in Revit, in one window

Platform | Revit
Stack | C# / .NET · WPF · Revit API · JSON · live language switching

View filters and visibility overrides are slow to manage in Revit, and they multiply over a project's life. ViewFilter brings all of it together: copy or remove filters between views and templates, audit the project for unused filters, empty rules and duplicates, move complete view templates to another project, and purge what's left over. The interface switches live between German and English.

Six tools in one

Design decisions

Audit is read-onlyScanning never changes the model, so it's safe on a live project.
Every cleanup can be undoneOperations run in transactions and can be reversed with Ctrl+Z until the file is saved.
Templates travel completeFilters, overrides and rules move between projects as JSON, with pattern and line files alongside.
Handles missing parametersIf a filter needs a shared parameter the target project lacks, the tool offers to create it.
Two languages liveThe UI switches between English and German without a restart.
