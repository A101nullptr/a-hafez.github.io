Anschlussreihenfolge

Wall junction order from rules, with room for exceptions

Platform | Archicad
Stack | C++ · Archicad API · CSV rule table

In Archicad, a wall's junction order decides how it connects to its neighbours, and setting it by hand across a project is slow and easy to get wrong. This add-on reads a CSV of rules and gives every wall the right base value from its classification, position and load-bearing function. A second command applies a per-wall modifier property, so exceptions stay deliberate and visible, and survive the next update.
