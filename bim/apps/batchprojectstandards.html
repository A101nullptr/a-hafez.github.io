BatchProjectStandards

One source model, many targets, no one at the keyboard

Platform | Revit · Autodesk Construction Cloud
Stack | C# / .NET · WPF · Revit API · Windows UI automation · SMTP

Transfer Project Standards is a manual dialog in Revit, one model at a time. This tool runs it across many cloud-hosted models unattended. You pick a source model, the target models and the standards to copy, and how duplicates should be handled. It then deploys an add-in, launches Revit and works through every target: transfer, synchronise with central, next. At the end it emails a per-target log and removes everything it installed.

How it works

Design decisions

Automating what has no APITransfer Project Standards isn't exposed in the Revit API, so a separate driver operates the real dialog.
Event-drivenThe add-in reacts to DocumentChanged and DocumentSynchronizedWithCentral instead of guessing with timers.
Config over rebuildThe folder tree, cloud GUIDs, recipients and parameter list live in one config file.
Proof of every runEach target's checklist and a summary are emailed as TransferLog.log.
Protected while runningUser input is blocked during the run, so a stray click can't break the sequence.
