WallSideVisualizer

See which way every wall faces

Platform | Revit
Stack | C# / .NET · Revit API · detail lines and filled regions

These walls are prefabricated, so it matters which side goes on the conveyor belt, and a normal floor plan doesn't show that. One click annotates every wall in the active view: a red line for its location, a triangle for the direction it was drawn in, and a green line on the finished face side. All annotation is collected in one detail group, which makes checking and removing it easy, angled walls included.
