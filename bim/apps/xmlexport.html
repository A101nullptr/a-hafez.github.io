XMLExport

A whole project's data structure, in one readable file

Platform | Revit · Excel, Tableau, SQL
Stack | C# / .NET · WPF · Revit API · .NET reflection · XML

Sometimes you need to see everything a model contains, to document it, compare two projects or feed another tool. XMLExport writes the project's whole structure to one XML file: project information, parameter definitions, view-filter rules, and every element with its properties and values. Walls get extra detail. Anything that couldn't be read goes into an error log beside the file, so gaps are visible rather than silent.

What's in the file

<Project_Information>     every property of ProjectInfo
<Parameter_List>          project, global and shared definitions
<Visibility_Graphics_Overrides_Filter_List>   filters with their rules
<Category_List>
  <Category Type="...">
    <Element_List Count="...">
      <Element Name="...">
        <Property_List>    properties, method results, parameter values

Design decisions

Open formatPlain XML opens in Excel, Tableau, SQL or any other analysis tool.
Honest about gapsUnreadable properties are logged instead of silently skipped.
Extra detail on wallsCross-section, flip state, width, structural usage and stacked-wall data are added.
