Exporter

One Inventor document, every format, every folder

Platform | Autodesk Inventor
Stack | C# / .NET · WinForms · Inventor API · JSON configuration

Releasing a design from Inventor means exporting to many formats and project folders, with exact file names. This add-in does one run for all of it: every selected format, into every selected folder. It finds the project folder from the document's stock number, builds names from iProperties, stamps the print date and time on the document, and asks before overwriting anything.
