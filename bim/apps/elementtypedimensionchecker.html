ElementTypeDimensionChecker

Model dimensions, checked against the catalogue

Platform | Revit · Excel
Stack | C# / .NET · WPF · Revit API · Excel · XML configuration

Each wall type has target dimensions kept in an Excel catalogue, and models drift from them. This add-in checks every wall whose ElementTyp starts with K- against the matching row in the catalogue, comparing depth, width and height in metres to six decimals. Every deviation is listed with the wrong dimension and its target value, and one click selects and zooms to that wall.
